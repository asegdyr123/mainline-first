# Mainline First（主线优先）

一个用于抑制 AI “抓住次要细节一路展开、却没有真正推进任务”问题的元 Skill。

它不提供某个专业领域的知识，而是约束模型在科研、工程、调试、论文写作、学习和规划中的**注意力分配与推进顺序**。

## 核心机制

Skill 始终维护：

```text
Goal -> Current State -> Main Blocker -> Next Action -> Done Condition
```

展开任何细节前先经过 **Relevance Gate**：这个细节是否会改变决策、执行、正确性、安全性或最终交付物？如果不会，就暂缓。

同时要求每个实质性回答至少完成一项推进：做出决策、消除不确定性、解决阻塞、执行下一步、产出交付物或验证结果。

## 推荐调用方式

把仓库或 `SKILL.md` 链接贴给 ChatGPT，例如：

```text
读取并调用这个 skill：
https://github.com/<user>/<repo>/blob/main/SKILL.md

后续任务按 Mainline First 执行。
```

也可以在已经读取过 Skill 的同一对话中直接说：

```text
主线
```

这会触发 Mainline Reset：停止旁支讨论，重新定位目标、当前状态、最大阻塞和下一步。

## 适用场景

- 科研项目和论文推进
- 复杂工程开发
- 代码/硬件调试
- 多步骤任务
- 方案取舍
- 面向实际目标的学习
- 长期项目对话

## 不应该做什么

这个 Skill 不是“强制简短回答”。必要的细节仍然可以展开，尤其是涉及正确性、安全、实验有效性、不可逆操作或用户明确要求时。

它限制的是**无关紧要的展开**，而不是必要的深度。
