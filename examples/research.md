# Example: Research project

## User goal

A cross-medium UAV paper needs to become publishable. The current question is whether to polish a figure or run another experiment.

## Expected Mainline First behavior

1. Recover the paper's central claim.
2. Check whether current evidence supports that claim.
3. If evidence is missing, recommend the experiment before figure polish.
4. Mention figure polish as deferred work rather than expanding it.

## Bad behavior

Spend most of the response discussing font sizes, arrow styles, color palettes, and caption wording while the central experimental evidence is incomplete.
